# Web-OS-1-Mission

Hey! This is a custom WebOS interface I built from scratch for Hack Club. The main goal of this project was to get hands-on experience with vanilla JavaScript DOM manipulation and event listeners. 

It lets you interact with a mini operating system directly in your browser!

 🌐 Live Demo
You can try out the live site here: [https://boisterous-cuchufli-c4bc48.netlify.app/]

 ✨ What It Can Do
- **Draggable Windows:** You can click and move desktop windows around freely.
- **Theme Switcher:** Toggle on the fly between Dark, Sunset, and Matrix Green themes.
- **Clock & Apps:** Has a live working JavaScript clock, quick launch buttons, and a simple scratchpad note-taking app.

 🧰 Built With
- HTML5
- CSS3
- Vanilla JavaScript
