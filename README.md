 Web-OS-1-Mission

Hey, this is my custom WebOS project created for Hack Club! I wanted to try building a desktop-like experience entirely inside the browser using plain HTML, CSS, and vanilla JavaScript without relying on any external frameworks.

## What I Built

Draggable Window System: Implemented custom mouse event listeners (`mousedown`, `mousemove`, `mouseup`) so desktop windows can be moved around freely on the screen.
  Dynamic Theme Switcher:  Created a theme toggle that updates CSS custom properties on the fly to switch between Dark, Sunset, and Matrix Green visual styles.
    Desktop Apps: 
    Clock App: A live updating digital clock built with standard JS time functions.
    Scratchpad:  A lightweight notes app where you can type quick notes directly in the OS interface.
    App Launchers: Quick access buttons to open different tools on the desktop.



 What I Learned

Building this helped me get a lot better at handling DOM manipulation and understanding how event listeners interact with UI elements. Figuring out the logic for dragging windows smoothly without causing weird glitches on the page was definitely the trickiest part but super satisfying once it clicked!
